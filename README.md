# caydanligin-kaynayip-unutulmasi-afet-ve-acil-durum-yonetimi-baskanligi
Çaydanlığın kaynarken unutulmasını resmi mutfak afeti, milli buhar egemenliği ihlali ve ocak protokolü sapması sayan; düdüğü siren, tezgahı afet bölgesi, 'az kalsın altını kapatırdım' cümlesini erken uyarı ihmal tutanağı ilan eden Başkanlık. Gerçekten çalışır. Çaydanlıklar artık afet bölgesidir.
